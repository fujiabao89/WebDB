# P0-03-followup：连接池可观测性与压力测试

> 状态：Ready｜风险：Medium｜依赖：P0-03、ADR-008｜Owner：fujiabao89｜建议实现者：Claude Code｜独立审查：Codex｜Issue：[#14](https://github.com/fujiabao89/WebDB/issues/14)｜完成期限：P0 结束前

## 目标与范围

补齐 PostgreSQL/MySQL Adapter 的连接池指标和有界压力测试，验证 ADR-008 的连接获取超时、三维执行准入、拒绝恢复以及高并发下的连接归还行为。

不修改 SQL 安全策略、公开 HTTP API、连接池默认值或生产部署参数。若验证结果要求改变 ADR-008 默认值，必须先升级 Owner 并单独修订 ADR。

## 验收标准

| 验收项 | 证据 |
| --- | --- |
| 可观测活跃池、活跃/空闲连接、连接获取超时及准入拒绝 | PG/MySQL 指标测试与字段说明 |
| 每用户 2、每工作区 10、每连接 5 的准入限制均有独立并发测试 | 确定性并发回归测试 |
| 连接获取超过 5 秒时稳定拒绝，且不存在无界等待队列 | 池耗尽与恢复测试 |
| 超时、取消、数据库错误和客户端断开后连接始终归还 | PG/MySQL 重复压力测试 |
| 测试仅使用合成数据库和最小权限账号 | CI 配置与权限验证 |

## 交接要求

记录压力参数、运行环境、原始测试结果和已知抖动范围。测试不得依赖真实凭证或生产数据库，不得通过延长超时、降低断言或跳过场景获得通过结果。
